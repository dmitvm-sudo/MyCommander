# 07. UX: Layout, фокус, карта клавиш

## 7.1 Layout главного окна

```
┌────────────────────────────────────────────────────────────────────┐
│ Toolbar: [Panels A] breadcrumb path          [Panels B] breadcrumb │
├──────────────────────────────────┬─────────────────────────────────┤
│ Табы панели A: [disk] [docs] [×] │ Табы панели B: [srv] [tmp] [×]  │
├──────────────────────────────────┼─────────────────────────────────┤
│ Список панели A (NSTableView)    │ Список панели B (NSTableView)   │
│ … курсор, выделение …            │ …                               │
├──────────────────────────────────┴─────────────────────────────────┤
│ Status: "/path · 12 431 files · 3 selected · FDA ✓ · queue: 2 active"│
├────────────────────────────────────────────────────────────────────┤
│ Command bar (⌘L): _                                            [^] │
│ [опция] Embedded terminal (⌃`) — 40% высоты                        │
└────────────────────────────────────────────────────────────────────┘
```

- Панели: константная высота строк; divider между панелями перетаскивается; геометрия сохраняется.
- Активная панель подсвечивается (acцентная рамка заголовка).

## 7.2 Правила фокуса

1. Ровно один фокус: `panelListA / panelListB / commandBar / terminal / dialog`.
2. `Tab` переключает активную панель (традиция TC); `⌃Tab` / `⌘⇧]` — следующая вкладка внутри той же панели.
3. Открытие диалога возвращает фокус источнику после закрытия; модальные только конфликты/подтверждения.
4. Курсор (cursor) — это «текущий файл» активной панели; операции F5/F6 берут selection или cursor.
5. Фильтр (F-10) — живёт внутри списка; ввод с клавиатуры активирует его без смены фокуса; Esc сбрасывает.

## 7.3 Карта клавиш (профиль «TC/NC classic», маппинг ANSI-US; всё ремапится в Settings; для RU-раскладок — профиль «macOS style» с ⌘-эквивалентами в том же ряду)

### Навигация
| Клавиши | Действие |
|---|---|
| ↑ / ↓ | курсор вверх/вниз (с прокруткой) |
| PgUp / PgDn | страница |
| Home / End | первый/последний элемент |
| Enter | открыть каталог/архив; файл — запуск (`open`) |
| Backspace / ⌘↑ | на уровень вверх |
| Tab | сменить активную панель |
| ⌃Tab / ⌃⇧Tab | вкладка панели вперёд/назад |
| ⌘T / ⌘W / ⌘⇧T | новая / закрыть / заново открыть вкладку |
| ⌘R | refresh панели |
| ⌘L | фокус в командную строку |
| Alt+F1 / Alt+F2 | hotlist: диски/закладки панели A / B (vM2: F-11) |
| ⌘D | добавить закладку текущей папки |
| ⌘G | «перейти к папке…» (ввод пути) |

### Выделение
| Клавиши | Действие |
|---|---|
| Ins (или ⊥ remap: ⌃Space) | инвертировать выделение, курсор +1 |
| Space | выделить файл / для папки — выделить + подсчитать размер |
| Num+ / Num− / Num* | выделить по маске / снять по маске / инвертировать всё |
| Num / | восстановить предыдущее выделение |
| ⌘A | выделить всё |

### Операции (источник — активная панель, приёмник — противоположная)
| Клавиши | Действие |
|---|---|
| F3 | просмотр (Lister) |
| ⌘Y / Space на невыделенном | Quick Look (уточнение T-13: Space остаётся выделением F-3, QL — ⌘Y) |
| F4 | редактировать во внешнем редакторе |
| F5 | копировать (Selection → target panel) |
| F6 | переместить/переименовать (диалог пути) |
| F7 | создать каталог |
| F8 / ⇧⌫ | удалить (⇧ — минуя корзину, с подтверждением) |
| ⌃A / ремап | Info/свойства (F-19) |
| F9 | меню настроек (аналог NC меню) |
| ⌘M | Multi-rename (M3) |
| ⌘B | compare/sync панели A↔B (M3) |
| ⌘F | полнотекстовый поиск (M3) |
| ⌃\` | встроенный terminal (M3) |
| ⌘, | настройки |

### В просмотрщике (Lister)
| Клавиши | Действие |
|---|---|
| PgUp/PgDn, Space/⇧Space | страница вперёд/назад |
| ⌃H | hex-режим |
| F7 (в Lister) | поиск в файле |
| Esc / F3 | закрыть |

### Command bar (⌘L) — язык команд
- `cd <path|..|~|bookmark-name>`; `mkdir <name>`; `touch <name>`; `open <file>`
- `du [path]` — размер каталога; `find <query>` — перейти к результатам поиска (M3)
- `! <shell-команда>` — выполнить в shell текущей папки (вывод в мини-консоль)
- Плейсхолдеры: `%f` имя под курсором, `%F` путь, `%d`/`%D` каталоги панелей, `%s` список выделенных
- История: ↑/↓; Tab — автодополнение путей.

## 7.4 Диалоги и мессенджинг ошибок

- Конфликт-диалог (F-5): превью-таблица двух файлов (иконки, размер, даты), кнопки Overwrite / Skip / Keep both / Cancel + чекбокс «Apply to all».
- Удаление: подтверждение только при `⇧⌫` или когда удаляется ≥ N элементов (N в settings, default 5).
- Ошиб: сообщение человеко-читаемое + «Details» (errno, источник) + кнопки Retry / Skip / Cancel для операций очереди.
