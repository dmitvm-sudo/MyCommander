# SDD — Software Design Document: MyCommander (рабочее название)

Двухпанельный файловый менеджер для macOS в традиции Norton/Total Commander.
Нативный, на Swift, с открытым исходным кодом (GPL-3.0-or-later).

## Правила чтения для AI-агентов (вайбкодинг)

1. Реализация идёт строго по milestone (см. `09`); задача — только та, что указана в `12-VibeCoding-TaskPlan.md`.
2. Не расширяйте scope задачи: что не в критериях «готово» — не пишем.
3. Все публичные контракты берутся из `05-DataModel-VFS.md` и `06-Subsystems-Design.md`. Изменение контракта = отдельная задача с правкой SDD.
4. Требования ссылаются по ID: `F-x` (фичи), `N-x` (нефункциональные), `R-x` (риски), `ADR-x` (решения), `M-x` (milestones).
5. Помечайте НЕОБХОДИМОЕ как MUST; не реализуйте SHOULD/WON'T вне своего milestone.
