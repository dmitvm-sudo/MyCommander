# 01. Обзор

## 1.1 Продукт

**MyCommander** (рабочее название; финальное имяScalar определяется позже и на SDD не влияет) — двухпанельный файловый менеджер для macOS в традиции Norton Commander / Windows Commander / Total Commander: быстрые панели слева/справа, клавиатурная навигация, очередь передач, архивы «как папки», сетевые источники через единое дерево.

Позиционирование — свободная ниша (research/03-analysis.md): на macOS нет нативного **Swift**-двухпанельника с открытым исходным кодом, очередью передач уровня ForkLift, встроенным terminal и Git-awareness.

## 1.2 Цели (v1.0)

1. Клавиатура важнее мыши: полный TC/NC-набор хоткеев с remapping.
2. Нативная скорость: мгновенный запуск и пролистывание, оптимизированный копи-движок (APFS `clonefile`, `fcopyfile`).
3. Очередь передач уровня ForkLift: прогресс, пауза/отмена, разрешение конфликтов, журнал — устраняется публичная «боль» Nimble Commander.
4. Единое дерево источников: локальные тома + архивы (zip/tar/gz/xz; 7z read) + SFTP — как обычные папки.
5. Дифференциаторы: встроенный PTY-terminal, macOS-native фичи (тэги, Quick Look, Spotlight), дружелюбный onboarding по Full Disk Access.
6. Open source GPL-3.0-or-later, hackable кодовая база (SPM-модули, протоколы, тесты).

## 1.3 Non-goals (не делаем)

- Не заменяем Finder полностью (не embedded-вкладки как TotalFinder).
- Не текстовый редактор: встроен только просмотрщик; редактирование — внешний редактор.
- Не App Store-версия (несовместимо с sandbox-моделью; ADR-2) — только direct + notarized DMG.
- RAR-распаковка в core не включается (лицензионные ограничения unrar); возможно позже отдельным модулем.
- Кроссплатформенность не является целью (ADR-1: macOS-only, Swift).
- Не собираем телеметрию по умолчанию (opt-in только crash-отчёты).

## 1.4 Целевая аудитория

- Разработчики и sysadmins, у которых «мускульная память» Total Commander/Norton.
- Продвинутые mac-пользователи, которым тесен Finder.
- Вторично: OSS-контрибьюторы (чистая Swift-база).

## 1.5 Глоссарий

| Термин | Значение |
|---|---|
| **Панель** (A/B) | Список-обзор каталога/источника; одна — слева, другая — справа |
| **Активная панель** | Панель в фокусе; операции F5/F6 идут из неё в противоположную |
| **Tab** | Вкладка панели: отдельный workdir + своя история выделения |
| **VFS** | Virtual File System — единый интерфейс всех источников (локальный том, архив, SFTP…) |
| **Transfer queue** | Очередь файловых операций с прогрессом/конфликтами/паузой |
| **Hotlist** | Быстрый список закладок папок (Alt-стиль NC) |
| **Quick filter** | Инкрементальный фильтр текущего списка при наборе текста |
| **Lister** | Встроенный просмотрщик (text/hex/image) |
| **Operation journal** | Журнал операций: прогресс, пауза/отмена, ограниченный undo |

## 1.6 Ключевые решения (ADR) — финальные

| ADR | Решение | Обоснование |
|---|---|---|
| ADR-1 | Swift 6, современный Xcode SDK, deployment target macOS 14+ (Sonoma); AppKit для панелей, SwiftUI для настроек/диалогов | Нативность и производительность; AppKit-путь доказан Nimble Commander/ForkLift |
| ADR-2 | Не-sandboxed приложение, direct-дистрибуция (notarization + Sparkle 2), FDA через onboarding; обязательна работа и без FDA | Sandbox не даёт Full Disk Access; Apple в окт. 2026 ужесточает FDA — graceful degradation обязательна |
| ADR-3 | Модульная SPM-структура (DomainKit/VFSKit/FileOpsKit/EnginesKit/ListViewKit/TerminalKit/ServicesKit) + App-таргет; DI конструкторами | Читаемость для AI-агентов, изоляция, тестируемость |
| ADR-4 | Архивы как VFS-адаптеры: SWCompression + ZIPFoundation | Активные проверенные Swift-библиотеки, без C-мостов на старте |
| ADR-5 | SFTP — Citadel (на swift-nio-ssh); SMB (AMSMB2) и S3 — после v1.0; FTP отложен | Нет зрелой Swift FTP-библиотеки; SFTP закрывает 90 % серверных сценариев |
| ADR-6 | **GPL-3.0-or-later**, исходники открыты | Подтверждено владельцем; все зависимости пермиссивные (GPL-совместимы) |
| ADR-7 | Встроенный terminal — SwiftTerm (PTY), MIT | Зрелая Swift-библиотека эмулятора терминала |
| ADR-8 | Плагины v1.x: нативный Swift-протокол-контракт; полноценный сторонний SDK — после v1.0 | Прямой перенос WCX/WFX (DLL) невозможен; свой контракт проще и безопаснее |

## 1.7 Соглашения документа

- Русский язык, термины кода — английские.
- ID-ссылки: `F-x` — фичи, `N-x` — нефункциональные требования, `R-x` — риски, `ADR-x` — решения, `M-x` — milestones, `T-x` — задачи вайбкодинга.
- Swift-сигнатуры в `05` и `06` — целевые контракты. Имена в реализации могут отличаться; изменение контракта оформляется как отдельная задача с правкой SDD.
