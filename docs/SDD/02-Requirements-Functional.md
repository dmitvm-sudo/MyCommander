# 02. Функциональные требования — карточки фич

Формат: **ID · Название · Приоритет (MUST/SHOULD/WON'T для v1.0) · Milestone**.
Каждая карточка: описание → критерии приёмки (Acceptance) → затронутые модули → зависимости.
Приоритеты: MUST v1.0 — без неё релиз не значим; SHOULD — желательно; WON'T — не в v1.0 (перенесено в v1.x).

## Группа: Обзор и навигация

### F-1. Двухпанельный обзор каталогов · MUST · M1
Две независимые панели (A слева, B справа), каждая показывает содержимое каталога локального VFS. Синхронные/несинхронные режимы, дифф-обновление списков (не полный reload) по FSEvents.
**Acceptance:**
- Открытие папки ≤ 300 мс (10 000 записей, P95), скролл 60 fps при 50 000 записей.
- Изменения в каталоге извне появляются в панели ≤ 1 с (FSEvents/ Debounce) без ручного refresh; ручной refresh тоже есть (`⌘R`).
- Сортировки: имя/расширение/размер/дата; папки-вверх закрепляются сверху (настраиваемо); помнятся per-folder.
- Переход в каталог: Enter или двойной клик; на родителя — Backspace/`⌘↑`.
**Модули:** ListViewKit, VFSKit, DomainKit.

### F-2. Табы · MUST · M1
Вкладки внутри каждой панели: у каждой tab свой workdir, история навигации (вперёд/назад), своё выделение.
**Acceptance:**
- Новая вкладка `⌘T`, закрытие `⌘W`; переоткрытие закрытой `⌘⇧T`.
- ≥ 20 вкладок на панель без деградации; состояние вкладок переживает рестарт приложения.
- Tab title = имя каталога; локированные вкладки (lock) не меняют папку, а «направляют» открытие в новую вкладку.
**Модули:** ListViewKit, ServicesKit (сессии).

### F-3. Модель выделения · MUST · M1
Классика NC/TC: Ins — инвертировать выделение и сдвинуться; Space — выделить + подсчитать размер папки; `+`/`−`/`*` (num) — выделить по шаблону / снять / инвертировать; выдели выживают после refresh, если объект существует.
**Acceptance:**
- Выделение не теряется при FSEvents-диффе и при смене сортировки.
- Пакетные операции применяются к выделению; при пустом выделении — к файлу под курсором.
- «Restore selection» восстанавливает предыдущее выделение (`Num /`).
**Модули:** ListViewKit, DomainKit.

### F-4. Режимы отображения · MUST (brief/full) M1 · SHOULD (custom columns, thumbnails) v1.0
- **brief** — только имена (макс. плотность, многоколонночный поток);
- **full** — таблица: имя, расширение, размер, дата, атрибуты;
- **custom columns** — конфигурируемый набор колонок (в т.ч. тэги/Spotlight-метаданные);
- **thumbnails** — миниатюры через QLThumbnailGenerator.
**Acceptance:**
- Переключение `⌃1..4` (remap), режимы независимы по панели; custom columns — конструктор (JSON-пресет).
- Thumbnails для ≥ 1 000 медиа-файлов без блокировок UI (генерация в фоне, lazy).
**Модули:** ListViewKit, ServicesKit (пресеты колонок).

## Группа: Файловые операции

### F-5. Движок файловых операций · MUST · M1
Copy/Move/Delete/Rename/Mkdir из активной панели. Все операции — через TransferQueue: прогресс per-file и общий, пауза/resume, отмена, перезапуск, разрешение конфликтов (overwrite/skip/rename-auto/cancel) с «Apply to all», фоновый режим (окно можно закрыть — операция живёт).
**Acceptance:**
- Копирование: APFS `clonefile` при равном томе (мгновенно); между томами — `fcopyfile` + temp-file + атомарный rename; уникальное имя auto-suffix (1).
- Move: в рамках тома — rename(2); между томами — copy+delete.
- Delete: опция «в корзину» (по умолчанию) и «насовсем» (remap-подтверждение); удаление деревьев показывает счётчик глубины.
- Конфликты: диалог с превью (размер/даты), выбор per-file или all; отчёт по завершении (ok/skip/fail/причины).
- Пауза/отмена реагируют ≤ 500 мс; очередь персистентна в течение сессии.
**Модули:** FileOpsKit, DomainKit, ListViewKit (прогресс-окно).

### F-6. Ограниченный undo · SHOULD · M2
Undo только для «журналируемых» операций: rename, mkdir, move в рамках тома, delete «в корзину» (возврат из корзины по записи о перемещении).
**Acceptance:**
- `⌘Z`/`⌃Z` возвращает последнюю операцию (список последних 20 в журнале).
- Пересечение с изменённым состоянием (файл уже занят/недоступен) → понятный диалог, частичный undo возможен.
*Уточнение T-20 (v1-сноски):* «список последних 20» — буфер журнала (JournalStorage ring из T-10), отдельного окна undo-истории в v1 нет — ⌘Z ходит по записям последовательно; «частичный undo» — существующие конфликты-диалоги с apply-to-all на реверс-плане.
**Модули:** FileOpsKit (Journal), ListViewKit.

## Группа: Клавиатура и командная строка

### F-7. Полная карта хоткеев + remap · MUST · M1
Дефолтная карта = OldSchool F1–F12/Ins (07-UX-Keyboard-Map.md) + Mac-конвенции (⌘C/⌘V/⌘X эмулируются через очередь). Remapping через Settings (JSON keymap-профили), международная обратная совместимость: профиль «macOS style» и «TC/NC style».
**Acceptance:**
- 100 % действий в UI доступны клавиатурой (без мыши).
- Конфликтующие байндинги подсвечиваются; сброс к дефолту — одной кнопкой.
- Single-key quick search активируется набором текста (или `/`), глофинтервальность = быстрый фильтр F-10.
**Модули:** ListViewKit (KeyBinder), ServicesKit (KeymapStore).

### F-17а. Командная строка панели · MUST · M1
Строка с ⌘-подстановками: `⌘L` фокус ввода; команды: `cd`, `mkdir`, `touch`, `open`, `sh -c`, `du`, `find`; плейсхолдеры `%f %F %d %D %s`;
**Acceptance:** вывод в мини-консоль внизу панели; ошибки понятны; история команд (↑/↓).
**Модули:** ListViewKit, TerminalKit (исполнение), ServicesKit.
*Уточнение T-14 (v1-скоуп):* `⌘L`-бар внизу главного окна: `cd`/`mkdir`/`open`/`!<shell>` + история ↑/↓ + плейсхолдеры %f %F %d %D %s (06 §6.8 «Контракт v1»); `touch`/`du`/`find` и Tab-автодополнение — следующая версия; исполнение `!` — exec-ветка `ShellSession` (PTY-терминал — F-17, M3).

## Группа: Просмотр

### F-8. Встроенный просмотрщик (Lister-lite) · MUST · M1
`F3` — просмотр: большие файлы (стримом, окно-скролл), text (UTF-8/16, авто-детект), hex-режим (`⌃H`), изображения через нативный рендер. `F4` — «редактировать» во внешнем редакторе (по умолчанию TextEdit/выбор).
**Acceptance:** файл 4 GB текста открывается мгновенно с индикатором позиции; просмотр корректен для файлов без newline; «view source» — локальный диск или VFS (архив, SFTP — поток).
**Модули:** ListViewKit (Lister window), VFSKit (stream).

### F-9. Quick Look интеграция · MUST · M1
`⌘Y` открывает QLPreviewPanel — нативный превью (уточнение T-13: Space в 02 F-9 конфликтовал с F-3 «Space — выделить»; Space остаётся выделением, QL — по `⌘Y`, перебиндить Space сможет ремап).
**Acceptance:** работает для любых QL-форматов; для файлов в архиве сохраняет в temp и preview; навигация ↑/↓ по списку внутри QL.
**Модули:** ListViewKit.

## Группа: Поиск и фильтр

### F-10. Quick filter текущей папки · MUST · M1
Набор текста фильтрует список (подстрока/fuzzy, настраиваемо), Enter — к первому совпадению курсором, Esc — сброс. Полнокрасочный индикатор «фильтр активен».
**Acceptance:** фильтрация 50 000 имён ≤ 50 мс (инкрементально), курсор остаётся в контексте.
**Модули:** ListViewKit, EnginesKit.

### F-16. Полнотекстовый поиск · SHOULD · M3, MUST v1.0
Диалог поиска: маска, размер, даты, regex, содержимое (text-search) + фильтры; поиск локально и по SFTP/архивам; результаты — виртуальная папка (работают фичи F-3/F-5/F-18); «отправить в панель».
**Acceptance:** отмена мгновенная; Spotlight-ускорение NSMetadataQuery на локальных индексируемых томах; лимит результатов + прогресс в очереди.
**Модули:** EnginesKit (Search), VFSKit.

## Группа: Навигация и закладки

### F-11. Закладки / Hotlist / история · MUST · M2
Favorites-боксы: папки, hotlist (modial Alt+F1… по 9 слотов) с «двойной адресацией» (target panel), недавние папки, история back/forward per tab.
**Acceptance:** закладка панельного каталога — `⌘D`; персистентность; hotlist вызов `Alt+двойная буква` — навигация обеих панелей опционально (опция « замок локации»).
**Модули:** ServicesKit (Locations), ListViewKit.

## Группа: VFS — источники

### F-12. Архивы как папки · MUST · M2
zip (read+write), tar/gz/xz/bzip2 (read), 7z (read, v1.0 SHOULD). Открытие архива = вход в каталог; копирование внутрь/наружу — через TransferQueue с распаковкой/упаковкой на лету.
**Acceptance:**
- Архивы > 4 GB; прогресс на элементах; русские/unicode-имена корректны (CP866 fallback).
- Pack: контекстное «Pack…» → формат опции, уровень, имя; фоновая упаковка в TransferQueue.
**Модули:** VFSKit (ArchiveVFS), FileOpsKit.
*Уточнение T-22 (v1-скоуп):* «Pack…» = zip-only контейнер (опция «метод сжатия»
mutually deflate/store; уровень сжатия ZIPFoundation не выставляет — честно в 06 §6.2);
«извлечь всё» в v1 = обычный F-5 copy-план из архив-панели в противоположную (planCopy
уже раскрывает дерево и стримит записи через `ArchiveVFS.openRead` — исполняется
очередью T-10, отдельный extract-all-контекст НЕ вводится).

### F-13. SFTP как папка + Connection Manager · MUST · M2
Создание/редактирование подключений (host, порт, учётные данные в Keychain, поддержка ssh-ключей и known-hosts); SFTP-панель ведёт себя как локальная (list/stat/read/write/rename/mkdir/rm).
**Acceptance:** reconnect/timeout/поток докачки — устойчиво; прогресс в TransferQueue идентичен локальным копиям; ошибки авторизации понятны; буферизация потоков без утечек памяти.
**Модули:** VFSKit (SftpVFS на Citadel), ServicesKit (Connections).

### F-25. SMB · WON'T v1.0 → v1.xWild — AMSMB2/libsm b2; F-26. S3/облака · v1.x (aws-sdk-swift); F-28. FTP · v1.x; F-29. Поиск дубликатов · v1.x; F-30. Split/combine/checksums · v1.x. Карманы-карточки: аналогичны F-13 (по структуре), полные спецификации пишутся при входе в v1.x.

## Группа: Инструменты

### F-14. Multi-rename · SHOULD M3 · MUST v1.0
Пакетное переименование: маска имени, счётчики, replace/regex, регистр, расширение; live-preview таблицей (old→new, конфликты), undo через F-6.
**Acceptance:** 10 000 файлов — предпросмотр ≤ 1 с; конфликтующие результаты красным; отмена до commit; сухой прогон без записи.
**Модули:** EnginesKit (Rename), ListViewKit.

### F-15. Compare / Sync каталогов · SHOULD M3 · MUST v1.0
Сравнение A↔B (по имени+размеру+дате, опционально содержимое), фильтры асимметричности; действие: копировать ← / →, зеркальная синхронизация (по умолчанию dry-run).
**Acceptance:** дерево-дифф для 100k записей ≤ 3 с (hash-ускорение, parallel); подтверждение перед изменениями; лог скрипта действий.
**Модули:** EnginesKit (Sync), FileOpsKit.

## Группа: Интеграция с macOS

### F-18. Drag & Drop обе стороны · MUST · M1
Перетаскивание из Finder в панель (copy через TransferQueue), из панели в Finder; drag внутри панели между табами; nsPasteboard Business (file URLs).
**Acceptance:** drag по сети/архиву работает симметрично (extract/copy); курсор-состояние адекватно (copy/move badges); drop в «домашнюю панель» — дефолт-цель.
**Модули:** ListViewKit, FileOpsKit.
*Уточнение T-16 (v1-скоуп):* Finder↔панель (LocalVFS: file URLs, copy) + panel↔panel (move по умолчанию, ⌥ = copy, самодроп — отказ; 06 §6.1 «Контракт v1 (T-16)»). Drag по сети/SFTP и «drop в архив — extract» — после ArchiveVFS/SftpVFS (M2); курсор-бейджи — по NSDragOperation.

### F-19. Info/свойства · MUST · M1
Диалог по `⌃A`-эквивалент (remap): size, dates, права, owner, xattr, тэги, содержимое папки (рекурсивный размер — фоново).
**Acceptance:** подсчёт размеров дерева не блокирует UI; копирование списка полей; работает для VFS-источников (модель-адаптер предоставляет метаданные).
**Модули:** ListViewKit, VFSKit.
*Уточнение T-15 (v1-скоуп):* карточка non-modal: name/kind/size/dates/permissions/owner/group/тэги + фоновый рекурсивный размер (06 §6.11 «Контракт v1»); копирование карточки текстом в Clipboard; xattr — следующая версия (вне `VFSItemAttributes`).

### F-20. Onboarding прав доступа

### F-20. Onboarding прав доступа · MUST · M1
Первый запуск: понятная графика «зачем нужен Full Disk Access»; кнопка ведёт в System Settings → Full Disk Access; после возврата app мягко проверяет доступ (проба чтения непубличного пути) и в падении показывает режим «Safe Mode» (только granted-папки: Desktop/Documents/Downloads по TCC, ~/Library…); состояние видно в статус-строке.
**Acceptance:** FDA granted → полный доступ без повторных промптов; denied → app fully usable на granted-путях, никаких crash; повторное предложение можно скрыть.
**Модули:** App (Onboarding), VFSKit (AccessProbe).
*Уточнение T-17 (v1-скоуп):* окно-предложение без графических иллюстраций (текст + 3 действия: System Settings / «Продолжить без FDA» / «Не показывать снова»); probe-обновление — на каждом `NSApplicationDidBecomeActive`; Safe Mode = бейдж в статус-строке + seed первого granted-папки при первом запуске без сессии (06 §6.10 «Контракт v1 (T-17)»); навязка — max 2 раза (§6.10), потом только бейдж.

### F-21. Настройки · MUST · M1 (базовые) · M3 (полные)
Панель настроек SwiftUI: ключи, тема, шрифт, формат колонок, поведение copy (confirm-диалоги), редактор по умолчанию, архивы, network-профили.
**Acceptance:** параметры применяются без рестарт; экспорт/импорт настроек (JSON); «reset section».
**Модули:** ServicesKit, App.
*Уточнение T-18 (v1-скоуп):* окна AppKit (не SwiftUI-панель — M3); секции: appearance (шрифт панели: mono-flag + size), deletion (confirm + threshold ≥N, 07 §7.3), editor (path, пусто = системный дефолт); применение без рестарта через `onDidUpdate`; экспорт/импорт JSON + reset section; schemaVersion = 1 заложена (06 §6.9 «Контракт v1 (T-18)»).

### F-22. Локализация EN/RU · MUST v1.0
String Catalogs; все строки UI локализуемы; даты/числа — locale-aware.
**Acceptance:** переключение языка системное; нет хардкoded строк в core-модулях (lint-правило).

### F-23. Темы · SHOULD v1.0
Light/Dark следуют системе; классическая «NC blue» скиная панелей и шрифт-тёмных; сохранение per-profile.
**Acceptance:** переключение темы — окументно живое (без рестарта).

## Группа: Дифференциаторы

### F-17. Встроенный PTY-terminal · SHOULD M3
Нижняя dispatchable-панель: терминал интегрирован по директории активной панели (cd авто-следит); включается `⌃`` · SwiftTerm-host: resize, copy/paste, link-follow, profile shell.
**Acceptance:** запуск в < 200 мс; работает tmux/ssh/vim без артефактов (на уровDelegate SwiftTerm); filePath-вставка из панели.
**Модули:** TerminalKit, ListViewKit.

### F-24. Git-осведомлённость · WON'T v1.0 → v1.x pilot
Колонка/бейджи git-статусов (modified/untracked) в панелях, если каталог внутри repo; настраивается как custom-column (провайдер G-status поверх «column-контракта» F-4).
**Acceptance (v1.x):** ≤ 50 мс сканирования на каталог 5k файлов; кэширование; не затрагивает производительность локального списка за пределами репо.

### F-27. Плагин-контракт · WON'T v1.0 → v1.x
Swift-протокол (сборка в XPC/процелесе или static link) + JSON-манифест: типы ColumnProvider/ViewerProvider/FSProvider/ActionProvider. Публичный SDK after v1.0.
**Acceptance (v1.x):** собственные Git/EXIF-провайдеры идут через этот контракт (dogfood-проверка).
